## 🔍 Overview

This document describes how to set up a **robust, encrypted, off-site backup system** for an Immich instance using:

- ☁️ **Backblaze B2**
- 🔐 **rclone (with crypt)**
- 🧩 Wrapper scripts for transactional backups
- ⏰ Weekly cron jobs
- 📲 Telegram reports with before/after state

The system backs up:

- 🖼️ **Immich library** (photos/videos)
- 🗄️ **Immich database backups**

---

## 📁 What is backed up (and what is not)

### ✅ Backed up

- **Library**
  ```text
  /mnt/nas/upload/library
  ```

- **Database backups** (generated by Immich)
  ```text
  /mnt/nas/upload/backups
  ```

### ❌ NOT backed up

* Thumbnails
* Cache
* Containers
* Immich binaries

These are reproducible and do not contain unique data.

## 📲 Telegram setup

### 1️⃣ Create a bot

1. Open Telegram → search `@BotFather`
2. Send `/newbot` and follow the prompts
3. Copy the **bot token**

### 2️⃣ Get your chat ID

Send any message to your bot, then:

```bash
curl "https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates"
```

Find `"chat":{"id":...}` in the response — that's your chat ID.

### 3️⃣ Configure the report script

Edit `/usr/local/bin/immich-backup/immich-backup-report.sh` and fill in:

```bash
TG_BOT_TOKEN="your_token_here"
TG_CHAT_ID="your_chat_id_here"
```

### 4️⃣ Optional: SOCKS5 proxy

If Telegram is not directly reachable from the host, enable the proxy toggle:

```bash
USE_PROXY=true
PROXY_URL="socks5h://USERNAME:PASSWORD@10.10.10.218:8388"
```

> 📌 The proxy URL follows curl's `--proxy` format.
> `socks5h` means DNS is resolved through the proxy (recommended).

### 5️⃣ Test delivery

```bash
curl -s -X POST "https://api.telegram.org/bot<TOKEN>/sendMessage" \
  -d "chat_id=<CHAT_ID>" \
  -d "text=Immich backup bot is working"
```

## ☁️ Configure Backblaze B2 in rclone

```bash
rclone config
```

### Remote 1: Backblaze B2

* Name: `b2immich`
* Type: `b2`
* Account ID: from Backblaze
* Application Key: from Backblaze
* Bucket: `myownserv-immich-backup`
* Defaults for everything else

Test:

```bash
rclone lsd b2immich:
```

---

### 🔐 Remote 2: Encrypted crypt remote

* Name: `b2immichcrypt`
* Type: `crypt`
* Remote: `b2immich:`
* Filename encryption: `standard`
* Directory encryption: `true`
* Password: **strong password**
* Salt: **store securely**

> ⚠️ **Losing the password or salt makes your data unrecoverable.**

Test:

```bash
rclone lsd b2immichcrypt:
```

## 🚀 Initial manual upload (once)

### 📁 Library

```bash
rclone sync /mnt/nas/upload/library b2immichcrypt:immich-library \
  --fast-list --transfers=4 --checkers=8 --metadata --progress
```

### 🗄️ Database backups

```bash
rclone sync /mnt/nas/upload/backups b2immichcrypt:immich-db \
  --fast-list --transfers=1 --checkers=4 --metadata --progress
```

## 🧩 Wrapper scripts (transactional backups)

These scripts capture **remote state BEFORE and AFTER** each backup, with mass-deletion protection guards.

---

### 📁 Library backup wrapper

**File:** `/usr/local/bin/immich-backup/immich-library-backup.sh`

```bash
chmod +x /usr/local/bin/immich-backup/immich-library-backup.sh
```

**Safety guard:** aborts if local file count drops below 70% of remote.

---

### 🗄️ Database backup wrapper

**File:** `/usr/local/bin/immich-backup/immich-db-backup.sh`

```bash
chmod +x /usr/local/bin/immich-backup/immich-db-backup.sh
```

**Safety guard:** aborts if local count is 0, or drops below 50% of remote.

---

## 🔄 Backup execution flow

**File:** `/usr/local/bin/immich-backup/immich-data-backup-flow.sh`

Runs all three scripts in sequence:

1. `immich-library-backup.sh`
2. `immich-db-backup.sh`
3. `immich-backup-report.sh`

✅ The Telegram report is **always sent**, even if a backup step fails.

# ♻️ Consolidated Immich Restore Guide

### *(Proxmox LXC + NAS)*

---

### 1️⃣ Stop Services

Mandatory to release database locks.

```bash
systemctl stop immich-web
systemctl stop immich-ml
```

---

### 2️⃣ Configure Storage Symlinks

```bash
rm -rf /opt/immich/upload
rm -rf /opt/immich/app/upload
rm -rf /opt/immich/app/machine-learning/upload

ln -s /mnt/nas/upload /opt/immich/upload
ln -s /mnt/nas/upload /opt/immich/app/upload
ln -s /mnt/nas/upload /opt/immich/app/machine-learning/upload
```

---

### 3️⃣ Restore the Database

```bash
sudo -u postgres dropdb immich
sudo -u postgres createdb immich

gunzip immich-db-backup-*.sql.gz
sudo -u postgres psql -d immich < immich-db-backup-*.sql
```

---

### 4️⃣ Synchronize Credentials

```bash
sudo -u postgres psql -c "ALTER USER immich WITH PASSWORD 'YOUR_PASSWORD_HERE';"

sudo -u postgres psql -d immich -c "GRANT ALL PRIVILEGES ON DATABASE immich TO immich;"
sudo -u postgres psql -d immich -c "ALTER SCHEMA public OWNER TO immich;"
```

---

### 5️⃣ Start and Verify

```bash
systemctl daemon-reload
systemctl start immich-web
systemctl start immich-ml

journalctl -u immich-web -n 50 -f
```

---

| Path                                      | Type    | Points To         |

| `/opt/immich/upload`                      | Symlink | `/mnt/nas/upload` |
| `/opt/immich/app/upload`                  | Symlink | `/mnt/nas/upload` |
| `/opt/immich/app/machine-learning/upload` | Symlink | `/mnt/nas/upload` |
